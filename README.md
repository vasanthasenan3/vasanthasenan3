## 🚀 Featured Project

### 🗓️ Mentor Application: Windows Desktop Companion

The desktop counterpart to a mentor-booking web app. It lets admins and mentors manage profiles, availability and appointments without needing a browser open.

**Tech:** C# · Windows Forms · SQL Server · ADO.NET · Entity Framework

- Built the desktop side for managing mentor profiles, skills and professional details
- Added scheduling screens and an appointment manager so admins can view, confirm, reject or cancel bookings
- Used ADO.NET and Entity Framework for the data layer, kept in sync with the same SQL Server database as the web platform
- Put together basic reporting for mentor activity, appointment history and booking trends
