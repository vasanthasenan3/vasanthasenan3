## 🚀 Featured Projects

### 1. Mentor Booking Platform

**Technologies:** C#, ASP.NET Core MVC, Entity Framework Core, SQL Server, ASP.NET Core Identity, OAuth, HTML, CSS, JavaScript, Bootstrap

A web application that connects mentees with mentors across different fields, allowing users to manage profiles, discover mentors and book sessions.

**Key Features**

* User authentication with email/password and Google/Facebook OAuth.
* Profile management with photo uploads and mentor/mentee role switching.
* Mentor availability management with recurring time slots.
* Mentor search and filtering by name, skill and title.
* Appointment booking workflow with Pending, Confirmed, Rejected, Cancelled and Completed statuses.
* Booking validation to prevent double-booking and self-booking.
* Database design and data access using Entity Framework Core.
* Booking notifications through SMTP integration.

### 2. Supermarket Billing System

**Technologies:** C#, Windows Forms, SQL Server, ADO.NET, Entity Framework

A Windows desktop application designed to manage supermarket operations, including inventory, billing, customer records and reporting.

**Key Features**

* Product management with category-based organization.
* Inventory tracking and automatic stock updates after sales.
* Billing functionality with discounts and receipt printing.
* Customer registration, profile management and order history.
* Sales and inventory reports to support day-to-day store operations.
* SQL Server integration for persistent application data.
